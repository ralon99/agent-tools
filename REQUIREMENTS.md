# Requirements

## General

- A shell the agent can run commands in (Bash/PowerShell — already available in
  Claude Code)

## github

- [`gh`](https://cli.github.com/) (GitHub CLI), installed and authenticated —
  check with `gh auth status`
- `git`
- Write access to a repo for branch/push/PR operations

## chrome

- Node.js (v20.11+, for `import.meta.dirname`)
- Google Chrome installed (Windows/macOS: standard install location; Linux:
  `google-chrome`/`chromium` on `PATH`)
- `npm install` once in `chrome/`
